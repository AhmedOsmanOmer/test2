# دليل الاستخدام حسب الدور

## الإشعارات (للجميع)
- **الجرس** أعلى الصفحة يعرض عدد غير المقروء ويتحدث تلقائيًا كل 15 ثانية دون إعادة تحميل، ويظهر العدد أيضًا في عنوان تبويب المتصفح. الإشعار الجديد يظهر لثوانٍ أسفل الشاشة.
- اضغط الجرس لرؤية آخر 10 إشعارات؛ الضغط على إشعار يفتح الطلب ويعلّمه كمقروء. «عرض الكل» يفتح صفحة الإشعارات، وفيها «تعليم كمقروء» لكل إشعار و«تعليم الكل كمقروء».
- اختياري من قائمة الجرس: «صوت عند وصول إشعار جديد»، و«تفعيل تنبيهات المتصفح» (للإشعارات المهمة فقط عندما تكون الصفحة في الخلفية، وتعمل على localhost أو عبر HTTPS).
- لا تحتوي الإشعارات أي مبالغ. موظف المبيعات لا يستلم إلا إشعارات طلباته، ولا يُشعَر أحد بإجراء قام به بنفسه.

## استيراد بنود الطلب من Excel (المدير العام، مشرف المبيعات، موظف المبيعات لطلباته)
1. **طلب قائم:** صفحة الطلب ← تبويب «المنتجات والمواصفات» ← «استيراد بنود من Excel» ← «تنزيل القالب».
2. املأ القالب (احذف صف المثال)، ثم اختر الملف ← «رفع ومعاينة».
3. راجع المعاينة: البنود الصالحة، وقائمة الأخطاء (الصف، العمود، القيمة، المشكلة)، وتنبيهات البنود المطابقة لبنود موجودة.
4. إن وُجد أي خطأ لا يُستورد شيء: صحّح الملف وارفعه من جديد. إن لم توجد أخطاء: «تأكيد استيراد N بند». تُضاف البنود ولا تُستبدل الموجودة.
5. **طلب جديد:** في صفحة «طلب جديد» ← «تعبئة البنود من Excel» ← «تعبئة البنود من الملف»؛ تُملأ صفوف المنتجات في النموذج، وتُحفظ مع الطلب كالمعتاد.

| العمود | مطلوب | القيمة |
|---|---|---|
| اسم المنتج | ✓ | نص، حتى 200 حرف |
| التصنيف | | اسم تصنيف موجود في النظام (قائمة منسدلة في القالب) |
| الكمية | ✓ | عدد صحيح أكبر من صفر (حتى 1,000,000)؛ تُقبل الأرقام العربية ٠-٩ |
| الوحدة | | الافتراضي «قطعة» |
| الطول، العرض، الارتفاع | | أرقام (سم) |
| الخامة | | حتى 100 حرف |
| سماكة الخامة | | حتى 50 حرفًا |
| نوع الطباعة | | حتى 100 حرف (قائمة مقترحة في القالب) |
| الألوان | | حتى 100 حرف |
| التشطيب، التغليف | | حتى 200 حرف |
| الوصف، ملاحظات فنية | | حتى 2000 حرف |

القواعد: ملف `.xlsx` فقط (لا .xls ولا .xlsm ولا .csv)، حتى 5 ميجابايت و500 صف، تُقرأ الورقة الأولى فقط، والصفوف الفارغة تُتجاهل، والصيغ تُقرأ بنتيجتها المحفوظة. **أي عمود مالي** (سعر، تكلفة، قيمة، مبلغ، إجمالي، خصم، ضريبة، price، cost، total…) **يرفض الملف كله** — قيمة الطلب يدخلها المخوّلون من صفحة الطلب. لا يمكن إضافة بنود بعد بدء الإنتاج، والحد الأقصى 500 بند للطلب. استيراد الملف نفسه مرة ثانية لنفس الطلب يحتاج تأكيدًا صريحًا، والمعاينة غير المؤكدة تنتهي بعد 24 ساعة. الملف نفسه لا يُحفظ في النظام.

## المدير العام
- **إضافة موظف:** الإعدادات ← المستخدمون ← حساب جديد (اسم مستخدم إنجليزي، الدور، كلمة مرور مؤقتة). يُجبر الموظف على تغييرها عند أول دخول.
- **تعطيل موظف غادر:** «تعطيل» ينهي جلساته فورًا ويحتفظ بكل سجله.
- **لوحة التحكم:** بطاقتا «قيمة الطلبات» (الطلبات المنشأة في الفترة دون الملغاة) و«المتبقي الإجمالي» تظهران للمدير العام فقط.
- **الإعدادات العامة:** بيانات الشركة (تظهر في سندات التسليم) وساعات العمل.
- **سجل التدقيق:** كل دخول وتعديل حساس، ومنه تفاصيل تعديل المبالغ (قبل/بعد).

## مشرف المبيعات
- يرى **كل الطلبات** وقيمة كل طلب والمتبقي، ويعدّل القيمة والمدفوع لأي طلب.
- **تأكيد الدفعة المقدمة:** صفحة الطلب ← بطاقة «الدفعة المقدمة» ← «تم استلام الدفعة المقدمة». ينتقل الطلب تلقائيًا من «انتظار الدفعة» إلى التصميم (أو تجهيز المواد إن لم يتطلب تصميمًا). إلغاء التأكيد يتطلب ذكر السبب.
- يغلق الطلب بعد التسليم الكامل والسداد الكامل.
- **تغيير موظف المبيعات المسؤول:** صفحة الطلب ← بطاقة «الموعد والمسؤول» ← اختر الموظف واكتب السبب ← «نقل الطلب». يُشعَر المندوبان ومدير العمليات.
- يصله تنبيه عند الإلغاء الجزئي لكمية («راجع قيمة الطلب») وعند اكتمال التسليم.

## موظف المبيعات
1. العملاء ← عميل جديد.
2. الطلبات ← طلب جديد: العميل، الموعد (لا يقبل تاريخًا ماضيًا)، المنتجات ومواصفاتها (بدون أسعار)، و«قيمة الطلب» (اختيارية الآن، ويمكن إدخالها لاحقًا). الطلب يُسند إليك تلقائيًا.
3. انقل الطلب: طلب جديد ← مراجعة ← (أدخل القيمة) ← انتظار موافقة العميل ← انتظار الدفعة.
4. سجّل المبلغ المدفوع من بطاقة «قيمة الطلب» في صفحة الطلب. تأكيد الدفعة المقدمة يتم من مشرف المبيعات.
5. ترى **طلباتك فقط** في القوائم والبحث وصفحات العملاء.
6. **تغيير موعد التسليم:** صفحة الطلب ← بطاقة «الموعد والمسؤول» ← الموعد الجديد (اليوم أو بعده) والسبب ← «تغيير الموعد».
6. لتكرار طلب سابق: ملف العميل ← «تكرار الطلب».

## مدير العمليات
- يرى كل الطلبات **بدون أي مبالغ**، وينشئ الطلبات ويختار موظف المبيعات المسؤول.
- الطلب ← تبويب التصميم ← إسناد مصمم. التصميم ← المهمة ← «اعتماد وإرسال للعميل» أو «إعادة للمصمم». بعد رد العميل: «تسجيل قرار العميل».
- إلغاء الطلب أو جزء من كمية منتج (مع السبب).

## المصمم
- «مهامي» أو «التصميم» ← افتح المهمة ← «بدء العمل» ← ارفع الملفات (AI, PSD, PDF, SVG, JPG, PNG, TIFF, EPS).
- كل رفع ينشئ نسخة جديدة ولا يمسح السابقة.

## مشرف الإنتاج
- «تجهيز المواد» مرحلة يدوية (لا ربط بمخزون).
- الطلب ← تبويب الإنتاج ← إنشاء أمر تشغيل: المنتج والكمية (يمكن تقسيمها لدفعات)، الآلة، الموظف، الموعد المخطط، المراحل. حدّد الموظف والآلة عند الإنشاء (تعديلهما لاحقًا غير متاح بعد).
- النظام يرفض حجز آلة في فترة متداخلة مع أمر آخر.
- الإنتاج ← الآلات: تسجيل عطل أو صيانة يوقف الأوامر الجارية ويظهر فورًا على شاشة التلفاز.

## موظف الإنتاج
- «مهامي» تعرض أوامرك. «بدء الإنتاج» ← «إنهاء مرحلة» ← سجّل المنجز والتالف (التالف يتطلب سببًا) ← «إنهاء الإنتاج وإرسال للجودة».

## مسؤول الجودة
- صفحة الجودة تعرض ما ينتظر الفحص. الرفض أو «إعادة عمل» ينشئ تلقائيًا أمر إعادة إنتاج ومهمة تصحيحية.

## مسؤول التسليم
- التسليم ← «تسليم» على الطلب (أو صفحة الطلب ← تبويب «التسليم») ← الكميات المسلّمة الآن (جزئي أو كامل) واسم المستلم.
- **صورة إثبات التسليم إلزامية** مع كل تسليم (جزئي أو نهائي): اضغط «التقاط صورة التسليم» — يفتح الجوال الكاميرا مباشرة (وعلى الكمبيوتر يفتح اختيار ملف). يمكن التقاط حتى 5 صور، وحذف أي صورة قبل الإرسال. زر «تسليم وإصدار سند» لا يعمل قبل وجود صورة واحدة على الأقل، ويظهر شريط تقدم الرفع.
- تُصغَّر الصور على الجهاز قبل الرفع (توفير البيانات، وتُحذف بيانات الموقع)، والمقبول JPEG أو PNG أو WebP حتى 8 ميجابايت للصورة.
- بعد التسليم تظهر رسالة التأكيد مع رابط «طباعة السند»، وتظهر الصور في قسم «إثبات التسليم» بصفحة الطلب لكل من يرى الطلب (موظف المبيعات لطلباته فقط)، مع اسم من سلّم ووقت التسليم. الضغط على الصورة يفتحها بملء الشاشة.
- الصور لا تُعدَّل؛ حذفها للمدير العام فقط مع ذكر السبب (يُسجَّل في التدقيق والسجل الزمني).
- يصله إشعار «طلب جاهز للتسليم» (ومعه موظف المبيعات المسؤول عن الطلب فقط).
